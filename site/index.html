Self-host

Up and running before your coffee cools.

Pull and start

One Docker Compose file. Multi-arch images for amd64 and arm64, so it runs on a Raspberry Pi too.

Open port 5050

Sign in as admin. Unless you set ADMIN_PASSWORD, the generated password is printed once in the logs.

Add your first vehicle

Your data stays in your own database. No account, no telemetry, no subscription.

$ git clone https://github.com/moshiur-hridoy/OdoDash.git
$ cd OdoDash
$ docker compose up -d
# → open http://localhost:5050
services:
  ododash:
    image: ghcr.io/moshiur-hridoy/ododash:latest
    container_name: ododash
    restart: unless-stopped
    ports:
      - "5050:5050"
    volumes:
      - ./data:/app/data
    environment:
      - SECRET_KEY=change-me
$ python3 -m venv venv && source venv/bin/activate
$ pip install -r requirements.txt
$ pybabel compile -d app/translations
$ python run.py
