Authentication

All API requests require authentication via an API key

Generate an API key from Settings → Integrations. Include your API key in every request using one of these methods:

Option 1: Authorization Header (Recommended)

Authorization: Bearer odo_your_api_key_here

Option 2: X-API-Key Header

X-API-Key: odo_your_api_key_here

Example Request

curl -X GET "{{ request.host_url }}api/v1/vehicles" \
  -H "Authorization: Bearer odo_your_api_key_here"

Roles

A key carries the role of the account that created it. A Contributor key may create, update and delete fuel logs and charging sessions only; a Viewer key may read but not write. Refused writes return 403 with the code permission_denied.

Base URL

{{ request.host_url }}api/v1

Vehicles

Manage your cars, vans, motorbikes, and scooters

GET /vehicles

List all vehicles you have access to (owned and shared)

Response

{
  "vehicles": [
    {
      "id": 1,
      "name": "My Car",
      "vehicle_type": "car",
      "make": "Toyota",
      "model": "Corolla",
      "year": 2020,
      "registration": "ABC 123",
      "vin": "...",
      "fuel_type": "petrol",
      "secondary_fuel_type": null,
      "tank_capacity": 50.0,
      "is_active": true,
      "created_at": "2024-01-15T10:30:00",
      "stats": {
        "total_fuel_cost": 1250.50,
        "total_expense_cost": 450.00,
        "total_distance": 15000,
        "average_consumption": 7.5,
        "last_odometer": 45000
      }
    }
  ],
  "count": 1
}

A vehicle whose odometer is metered in engine hours rather than distance reports total_distance in hours and average_consumption in litres per hour. The tracking unit is set on the vehicle page and is not currently exposed or settable over the API; vehicles created here are tracked by distance. On a vehicle with a secondary_fuel_type that it actually burns, such as a petrol car converted to LPG, average_consumption covers the primary fuel only — each fuel is averaged on its own, and the per-fuel figures are shown on the vehicle page.

Fuel Logs

Track fuel fill-ups and consumption

GET /vehicles/{id}/fuel

List fuel logs for a vehicle

Query Parameters

Parameter Default Description
limit100Maximum results (max: 500)
offset0Results to skip for pagination
sortdescSort by date: asc or desc

Response

{
  "fuel_logs": [
    {
      "id": 1,
      "vehicle_id": 1,
      "date": "2024-01-20",
      "odometer": 45000,
      "volume": 45.5,
      "price_per_unit": 1.45,
      "total_cost": 65.98,
      "sales_tax": 8.58,
      "fuel_type": "petrol",
      "fuel_distance": null,
      "is_full_tank": true,
      "is_missed": false,
      "station": "Shell",
      "notes": null,
      "consumption": 7.2,
      "created_at": "2024-01-20T14:30:00"
    }
  ],
  "count": 1,
  "total": 25,
  "limit": 100,
  "offset": 0
}

fuel_type is the fuel the fill-up actually put in; logs recorded without one report the vehicle's own fuel type. fuel_distance is the distance run on that fuel since the previous fill-up of it, in the vehicle's own unit, and is only needed on a vehicle that burns two fuels — the odometer cannot say which of the two propelled which part of the distance. Both can be set when creating or updating a fill-up.

Request Body

Field Type Required Description

    "volume": 45.5,
    "price_per_unit": 1.45,
    "is_full_tank": true,

  }'

Error Handling

All errors return a consistent JSON format

Error Response Format

{
  "error": "Human-readable error message",
  "code": "error_code"
}

HTTP Status Codes

Code Error Code Description
200-Success
201-Created successfully
400invalid_request, validation_errorBad request or validation failed
401missing_api_key, invalid_api_keyAuthentication required or failed
403forbidden, permission_deniedPermission denied. permission_denied means the account's role does not allow this change
404not_foundResource not found

Rate Limiting

Currently, there are no rate limits on the API. Please be considerate with your request frequency.
